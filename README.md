# Fall in Love in One Line

An entry for the [make.fun "Make the Judge Fall in Love in One Line" bounty](https://make.fun/bounty/u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13).

One line, 125 characters, written to make the judge fall in love with a person — through a small, specific, quietly kept detail, and a confession made to the reader instead of to her.

> She still cuts the crust off my toast the way her mother did, and I have never once told her I noticed, but I am telling you.

The program (`main.ts`, Node 22, standard library only) writes the line to `/output/entry.txt`. It is deterministic: no network, no clock, no randomness — every run writes the same bytes.
